# 🎨 Random Avatar Generator

A clean, responsive, and modern React web application built with **TypeScript**, **Tailwind CSS**, and **Remix Icon** that allows users to seamlessly generate and download unique avatars for profile pictures, social media, or web projects.

---

## ✨ Features

* **Diverse Avatar Styles**: Supports vector/art styles (*Illustration*, *Adventurer*, *Lorelei*, *Robots*, *Pixel Art*) and realistic photo styles (*Male*, *Female*).
* **Instant Randomization**: Generate fresh random avatars on demand using randomized seeds and portrait IDs.
* **Direct Image Download**: Easily save generated avatars directly to your device with a single click.
* **Custom Glassmorphism UI**: Built with modern ambient blur gradients, loading spinners, and an interactive dropdown selector featuring outside-click detection.
* **Fully Responsive**: Optimized for smooth user experience across desktop, tablet, and mobile devices.
* **Type-Safe**: Developed using TypeScript interfaces for robust code quality.

---

## 🛠️ Tech Stack

* **Frontend Framework**: [React](https://react.dev/) (TypeScript)
* **Styling**: [Tailwind CSS](https://tailwindcss.com/)
* **Icons**: [Remix Icon](https://remixicon.com/)
* **External APIs**:
  * [DiceBear API v9](https://www.dicebear.com/) (Vector & Art avatars)
  * [RandomUser API](https://randomuser.me/) (Realistic profile portraits)
